# Itaú Customer Service Dashboard - Power BI

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio de Business Intelligence inspirado no Itaú, com foco na análise de atendimentos, desempenho operacional e indicadores de suporte ao cliente.

Diferente de um projeto baseado apenas em uma base pronta, neste desafio a base de dados foi criada do zero, simulando um cenário realista de atendimento. A proposta foi estruturar os dados, definir campos relevantes, criar indicadores e desenvolver um dashboard executivo no Power BI para apoiar a análise e a tomada de decisão.

## 🎯 Objetivo

Construir uma base de dados fictícia e um dashboard interativo em Power BI capaz de analisar o desempenho dos atendimentos e responder perguntas de negócio como:

- Quantos atendimentos foram registrados?
- Qual é o status dos atendimentos?
- Quais canais concentram maior volume de chamados?
- Quais categorias apresentam maior demanda?
- Como os atendimentos se distribuem ao longo do tempo?
- Quais indicadores ajudam a acompanhar a operação?
- Onde existem possíveis gargalos ou oportunidades de melhoria?

## 🧱 Criação da base de dados

A base de dados utilizada neste projeto foi criada do zero, com o objetivo de simular um ambiente real de atendimento ao cliente.

Foram definidos campos como:

- ID do atendimento
- Data de abertura
- Canal de atendimento
- Categoria do chamado
- Status do atendimento
- Prioridade
- Tempo de resolução
- Responsável ou equipe
- Cliente ou perfil do cliente
- Região
- Indicadores operacionais

A criação da base permitiu trabalhar desde a estruturação inicial dos dados até a construção dos indicadores finais no Power BI.

## 🛠️ Ferramentas utilizadas

- Power BI
- Power Query
- DAX
- Excel
- Modelagem de dados
- Criação de base de dados
- Visualização de dados

## 📊 Principais indicadores

Durante o desenvolvimento do projeto, foram criados indicadores para acompanhar o desempenho da operação de atendimento:

- Total de atendimentos
- Atendimentos por status
- Atendimentos por canal
- Atendimentos por categoria
- Atendimentos por prioridade
- Tempo médio de resolução
- Volume de atendimentos por período
- Distribuição de chamados por região
- Indicadores de performance operacional

## 🧠 Etapas do projeto

O projeto foi desenvolvido seguindo um fluxo completo de análise de dados:

1. Definição do objetivo da análise
2. Criação da base de dados do zero
3. Estruturação das colunas e regras da base
4. Importação dos dados no Power BI
5. Tratamento e padronização no Power Query
6. Ajuste dos tipos de dados
7. Criação de medidas DAX
8. Desenvolvimento dos indicadores executivos
9. Construção dos visuais analíticos
10. Aplicação de filtros interativos
11. Organização do layout e storytelling do dashboard

## 📈 Visuais desenvolvidos

O dashboard foi estruturado com diferentes visualizações para facilitar a leitura dos dados:

- Cards com indicadores principais
- Gráficos de barras para comparação por categoria e canal
- Gráficos de linha para análise temporal
- Gráficos de rosca para distribuição de status
- Tabelas analíticas
- Segmentadores interativos
- Indicadores de desempenho operacional
